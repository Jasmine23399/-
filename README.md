## 已实现的演示流程

- 设备台账：录入、编辑、按类别筛选与关键词搜索，记录编号、型号、使用人、部门、位置和购买日期。
- 转移审批：提交申请，审批通过后修改台账中的使用人；驳回保留记录。
- 报废清理：提交申请，审批通过后将设备标记为已报废。
- 智能清点：上传单张图片、选择类别、填写模拟识别数量，与指定区域的台账数量比对，并保存盘盈盘亏记录。
- 生命周期建议：根据使用年限和维修次数生成演示规则建议。
- 总览和统计：展示设备、审批、类别及清点数据。

## 源码结构

- `index.html`：页面容器及脚本加载顺序。
- `style.css`：全站样式。
- `app.js`：页面入口、导航和整体渲染。
- `src/data.js`：演示设备、共享状态和本地存储。
- `src/views.js`：各功能页面的 HTML 视图。
- `src/actions.js`：录入表单、审批、图片上传与清点交互。

演示数据保存在浏览器 `localStorage` 中。智能清点尚未连接多模态模型，生命周期建议尚未连接大语言模型。页面明确标注了这两项的模拟性质。使用 VS Code 的 Live Server 时，`index.html` 是入口。
