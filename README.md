# 基于大模型的智能设备管理系统 · Vue 前端原型

本项目根据开题报告和老师的要求搭建。当前是 Vue 3 + Vite 前端演示版，包含设备台账、转移审批、报废清理、图片清点、生命周期建议和统计页面。

## 在 VS Code 中运行

打开本项目文件夹，在终端执行：

```bash
npm install
npm run dev
```

按终端显示的 Local 地址打开页面，通常是 `http://localhost:5173/`。修改 `.vue` 文件后，Vite 会自动更新页面。生产构建使用 `npm run build`。

直接双击 `index.html` 或使用 Python 静态服务器无法运行这版 Vue 单文件组件；开发时使用 Vite。

## 源码结构

- `src/App.vue`：整体布局、导航和页面切换。
- `src/pages/`：各业务功能页面。
- `src/components/`：设备表格、状态标签和类别统计等共用组件。
- `src/store.js`：演示设备数据、共享状态和浏览器本地存储。
- `src/main.js`：Vue 应用入口。
- `style.css`：全站样式。

演示数据仍保存在浏览器 `localStorage`，沿用旧版的数据键。浏览器按地址和端口隔离本地存储，因此旧的 `localhost:8080` 页面里手动录入的数据不会自动出现在新的 Vite 地址中；源代码中的默认演示数据会正常加载。图片清点的识别数量目前由用户填写，生命周期建议由演示规则生成；两项尚未连接大模型。下一步应通过 Spring Boot API 管理数据库台账、审批与图片清点结果，前端不直接连接 MySQL。
